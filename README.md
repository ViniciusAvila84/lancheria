# Projeto Local

Este é um projeto web simples para começar localmente na sua máquina.

## Como executar

1. Abra o terminal
2. Acesse a pasta do projeto
3. Rode o comando:

```bash
python3 -m http.server 3000
```

4. Abra no navegador:

```text
http://localhost:3000
```

## Estrutura

- `index.html` - página principal
- `styles.css` - estilos visuais
- `script.js` - interações do frontend
